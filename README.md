# TALLY2EMAIL_AUTOMATION
A lightweight web app that transforms raw Tally exports into clean, professionally formatted Excel reports — no manual cleanup needed.
### What it does:
The app takes your Tally data export and automatically processes it end-to-end. Invoices are sorted by invoice number in ascending order, with all incomplete/pending invoices pushed to the bottom, keeping your completed transactions front and center. The Sales column preserves the original currency formatting straight from Tally, and dates are formatted to your specified standard consistently across the sheet. The final output is a polished Excel file with table filters and conditional formatting applied, ready to share or archive.
How it's delivered:
The entire workflow runs inside a browser-based web app, hosted on Netlify via Netlify Drop — meaning there's nothing to install. Users simply open the link, upload their Tally export, and download the formatted Excel file in seconds.
Key Features:

Auto-sorts invoices by invoice number
Incomplete invoices automatically grouped at the bottom
Currency format retained from Tally source data
Consistent, specified date formatting throughout
Excel output with column filters and clean table formatting
Zero-install, browser-based — accessible from any device
Instant deployment via Netlify Drop

🚀 How to Run the App via Netlify Drop
Step 1: Download the ZIP from this Repository

In this GitHub repo, click on TALLY2EXCEL_AUTOMATION.zip
Click Download raw file (the download icon on the right)
The ZIP file saves to your system


Step 2: Go to Netlify Drop

Open your browser and go to 👉 app.netlify.com/drop
You'll see a drag-and-drop zone that says "Drag and drop your site folder here"


Step 3: Drop the ZIP

Drag the downloaded TALLY2EXCEL_AUTOMATION.zip file directly onto the Netlify Drop page
Netlify will automatically extract and deploy it
Within seconds, you'll get a live URL like:

   https://random-name-123.netlify.app

Click that link — your app is live and ready to use ✅


⚠️ Important Notes

No account needed on Netlify for basic drop hosting
The link stays live for as long as the session is active
For a permanent link, sign up/log in to Netlify before dropping
Every time you drop, you get a new unique URL



💡 Tip: Once you get your Netlify link, bookmark it or share it directly — no re-uploading needed until you update the project.
